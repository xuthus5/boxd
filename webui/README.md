# Boxd Control Web Console

通过 REST + SSE 接入真实控制面的浏览器控制台。静态资源由 `webfiles.go` 内嵌到 `boxd`，生产环境不需要单独部署前端服务。

## 范围

- 覆盖总览、入口、出口编排、路由、订阅、规则集、观测、流式日志和设置。
- 总览采用统一健康状态条组织实时通道、内核、采样、出口与快照信息，并集中展示流量、连接和订阅状态。
- 总览的实时刷新与内核状态变更采用原地更新，不重播页面入场动画，避免启动内核时出现布局抖动。
- 总览按控制面健康、内核运行时、核心指标、流量与连接、订阅与快捷操作的优先级统一排列桌面端和移动端内容。
- 所有写操作调用真实 `/api/v1` 接口；页面状态来自控制面快照，日志与流量由 SSE 推送。
- 首次访问完成管理员口令初始化，后续使用同源会话登录；会话失效会自动回到登录页。
- 登录页提供清晰的访问安全说明，支持口令可见切换和深浅主题切换；不展示已知连接地址等冗余信息。
- 不包含控制面以上的真实应用接入，也不包含备份/恢复能力。
- 不提供 Web 终端或任意命令执行入口；运行态仅通过只读观测与流式日志查看。
- 日志页合并展示控制面应用与 sing-box 内核日志，支持来源、级别、关键词筛选以及暂停、清空和自动滚动。
- 节点支持订阅同步与分享链接导入；导入弹窗可解析 SS、VMess、VLESS、Trojan、Hysteria2、SOCKS 和 HTTP 链接。

## 本地运行

```bash
cd /root/projects/beatv2
go run ./cmd/boxd -data-dir ./tmp-data -web -listen [::]:7662
```

访问 `http://127.0.0.1:7662/`。前端只使用相对路径，因此必须由 `boxd` 同源提供；不要用独立静态服务器验收真实接口。

## 交互

- 左侧导航切换页面，URL hash 可用于直达，例如 `#egress`。
- 节点导入、节点测速、策略组切换、规则开关、订阅刷新、连接关闭等都会调用控制面并持久化。
- 前端不包含 Shell、终端、备份或恢复入口。
- 顶部搜索区域已替换为主题切换按钮，可在浅色与深色模式之间即时切换；选择会保存在本地。
