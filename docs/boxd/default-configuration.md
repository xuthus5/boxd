# 默认配置策略

默认配置面向当前固定的 sing-box 1.13.21，采用国内直连、其他代理的规则模式。

## 首次启动

- 配置文件不存在时，服务端与内嵌桌面端共用初始化逻辑，一次生成入站、出站、DNS、路由、日志和 Experimental。
- 四份完整规则快照随二进制提供，初始化不依赖网络。规则文件与配置文件权限为 `0600`，新目录为 `0700`。
- 已有配置、有效配置软链接和缓存保持不变。失败或取消不会留下半成品配置；并发创建不会覆盖另一份配置。
- mixed 只监听 `127.0.0.1:1080`。Linux 同时具备有效 `CAP_NET_ADMIN` 与 TUN 设备访问权时自动加入 TUN，并设置严格路由与出口接口检测；其他环境可在授权后手动添加 TUN。
- 内核是否自动运行仍遵循“内核自启”设置。首次使用应先添加节点或订阅，再启动内核。

## DNS 与分流

| 场景 | 默认行为 |
| --- | --- |
| 进入内核的 TCP/UDP 53 请求 | 在嗅探前劫持，交给内核 DNS |
| 非 53 端口的普通 DNS | 嗅探识别后劫持 |
| 广告域名 | DNS 返回空答案，连接使用 `reject`，不查询上游 |
| 两份域名列表重叠 | DNS 与路由均优先代理，避免直连覆盖代理要求 |
| 国内域名 | 经直连 DoH `223.5.5.5` 解析并直连 |
| 其他域名 | 经代理访问 DoH `8.8.8.8`，验证 `dns.google` TLS 证书 |
| 未被域名规则决定的连接 | 先按 DNS 策略解析，再匹配私网与中国 IPv4/IPv6；其余走代理 |
| 代理节点服务器域名 | 独立使用直连 DoH 引导，避免代理与 DNS 的启动依赖环 |
| 无节点或最后节点被删除 | 代理选择器使用阻止出站；不会回退直连 |
| 代理或远端 DNS 故障 | 返回失败，不查询系统 DNS 或直连解析器 |
| 显式选择 Direct 模式 | 用户主动选择直连与直连 DoH |
| 显式选择 Global 模式 | 公网业务流量及其 DNS 走代理；保留 LAN 与 ICMP 绕过 |

默认保留正常 QUIC，不注入缺少对应策略路由的 `routing_mark`。两组 DNS 使用独立缓存；没有未引用的 Local/FakeIP DNS，也不额外安装重复的 geosite 规则集。

TUN 保护进入其路由范围的系统 DNS；仅使用 mixed 时，应让客户端通过 SOCKS5 传递域名（例如 `socks5h`）。绕过代理的应用、排除的接口或进程，以及客户端自行启用的 DoH/DoT，不属于 mixed DNS 劫持范围。不得把“代理内 DNS 不回退”解释成“所有应用的系统流量均已接管”。

## 出站与状态

初始只生成实际需要的 direct、阻止出站和 proxy 选择器。添加节点后自动接入 proxy，保留仍有效的用户组与选择；订阅按已有 URLTest 设置决定是否自动测速。不额外生成未引用的 auto、whitelist 或 blacklist 组。

Clash 模式控制使用 boxd 内部接口，不额外开放 `9090`。选择状态缓存位于数据目录的 `cache.db`；用户明确的控制器、缓存路径与禁用设置得到保留。证书、NTP、辅助 Services 等未启用模块不生成空段。

## 规则与维护

默认规则为 Loyalsoldier direct/proxy/reject 和 china-operator-ip IPv4/IPv6。版本、完整性摘要、上游地址及许可证见[资源说明](../../internal/core/ruleset_bundle/README.md)。已有有效缓存保留更新时间，不把安装时间当成数据更新时间；可通过规则集页面更新或启用定时更新。

手动安装 DNS 或路由默认值也会在一次配置应用中补齐所需依赖。默认路由只重排结构完全等价的已知旧模板，自定义匹配条件与相对顺序保持不变；DNS 劫持与广告拒绝始终位于安全前导位置。已有不安全的 DNS 代理拓扑会返回明确错误，不静默改为直连。

验证包括全仓 Go 测试、race、覆盖率门禁、golangci-lint、前端检查，以及真实 sing-box 的 DNS/路由匹配与隔离网络启动测试。
